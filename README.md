# INF.04 – Rozwiązania Arkuszy Egzaminacyjnych

Repozytorium zawiera uporządkowane rozwiązania arkuszy egzaminacyjnych **INF.04 – Technik programista**, zgodnych z wymaganiami Centralnej Komisji Egzaminacyjnej (CKE).

Materiały zostały przygotowane w celach **edukacyjnych**, z myślą o analizie zadań, nauce oraz przygotowaniu do egzaminu zawodowego.

---

## Zakres repozytorium

W repozytorium znajdują się:
- rozwiązania zadań praktycznych i teoretycznych,
- kompletne struktury projektów zgodne z poleceniami egzaminacyjnymi,
- opisy zastosowanych rozwiązań,
- linki do oryginalnych arkuszy oraz zasad oceniania.

---

## Współtworzenie repozytorium

Repozytorium jest otwarte na współpracę.

### Pull Requests
Pull requesty są mile widziane w przypadku:
- dodania nowych arkuszy lub brakujących roczników,
- zaproponowania alternatywnych rozwiązań,
- poprawy błędów merytorycznych lub technicznych,
- refaktoryzacji kodu lub poprawy czytelności.

Każdy dodany arkusz powinien zawierać:
- link do arkusza egzaminacyjnego (CKE),
- link do zasad oceniania,
- kompletne rozwiązanie wraz z opisem.

### Issues
Issues należy wykorzystywać do:
- zgłaszania błędów,
- zadawania pytań dotyczących rozwiązań,
- omawiania wątpliwości interpretacyjnych poleceń egzaminacyjnych.
