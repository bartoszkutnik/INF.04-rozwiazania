# 📘 INF.04 – Rozwiązania Arkuszy Egzaminacyjnych

📌 Repozytorium zawiera uporządkowane rozwiązania arkuszy egzaminacyjnych **INF.04 – Technik programista**, zgodnych z wymaganiami **Centralnej Komisji Egzaminacyjnej (CKE)**.

📚 Materiały zostały przygotowane w celach **edukacyjnych**, w szczególności do nauki, analizy zadań oraz przygotowania do egzaminu zawodowego.

💻 **Wykorzystywane technologie i środowiska programistyczne:**
* ⚙️ **Aplikacje konsolowe:** Java (tworzone w IntelliJ IDEA)
* 🖥️ **Aplikacje desktopowe:** Java Swing (tworzone w IntelliJ IDEA)
* 📱 **Aplikacje mobilne:** Android Studio
* 🌐 **Aplikacje webowe:** React JS
* 🧪 **Testy jednostkowe:** JUnit

---

## 🎯 Zakres repozytorium

W repozytorium znajdują się:

* 📄 arkusze egzaminacyjne INF.04
* 📝 zasady oceniania (kryteria oceniania CKE)
* 📦 pliki do zadań (załączniki .zip / .7z)
* 💻 kompletne rozwiązania zadań
* 🧠 opisy zastosowanych rozwiązań i decyzji projektowych
* 🗂 uporządkowana struktura katalogów
